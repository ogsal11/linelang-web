# LineTranslate Web (Phase 2 대안)

Xcode/Mac 없이 쓸 수 있는 순수 클라이언트 웹페이지 버전. 서버·백엔드 없음 — `index.html` 하나로 끝나며, 브라우저에서 **Google Gemini API**(무료 티어, 카드 등록 불필요)를 직접 호출한다.

## 사용법

1. 라인 대화방 → **번역하고 싶은 과거 시점까지 미리 위로 스크롤해서 화면에 불러온 뒤** → 설정 → 대화내용 내보내기 → "파일에 저장" (Files 앱 / 원하는 폴더)
   - 내보내기는 화면에 이미 로드된 대화만 포함한다. 스크롤 안 한 과거 대화는 빠진다.
2. `index.html`을 아이폰 Safari(또는 아무 브라우저)로 열기
   - 로컬 파일로 열거나, GitHub Pages 등에 올려서 URL로 접속해도 됨
3. ⚙️ 설정에서 Gemini API 키 입력 — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 구글 계정으로 무료 발급 (Flash 모델 기준 하루 1,500회, 카드 불필요). 브라우저 localStorage에만 저장됨, 다른 사람과 공유되는 배포라면 절대 넣지 말 것.
4. 📥 버튼으로 방금 내보낸 .txt 선택 → 파싱 → 번역 → 채팅방처럼 표시

## Gemini 무료 티어 관련 참고

무료 티어 사용 시 입력 데이터가 구글의 모델 개선에 활용될 수 있다고 공식적으로 밝히고 있다. 개인 채팅 번역이라 민감도가 낮긴 하지만, 신경 쓰인다면 결제 등록 후 유료 티어(데이터 미활용)로 전환하는 것도 고려할 것.

## 알려진 한계

- iOS Safari는 Web Share Target API/File System Access API를 지원하지 않아 "내보내기 즉시 완전 자동 로드"는 불가능하다. 내보내기 → 파일 선택 1회 탭이 최소 동작이다.
- `parseLineExport()`는 실제 라인 PC(Windows) 내보내기 샘플로 검증된 포맷(`오전/오후 HH:MM<TAB>발신자<TAB>메시지`, 여러 줄 메시지는 큰따옴표로 감쌈)을 기준으로 한다. 라인 앱/OS 버전에 따라 세부 표기가 다를 수 있어, 안 맞으면 `index.html`의 `dateLineRe`/`messageStartRe`를 조정해야 한다.
- 파일 인코딩은 UTF-8을 우선 시도하고, 유효하지 않으면 EUC-KR(CP949)로 재시도한다(`readFileSmart`). 그 외 인코딩(UTF-16 등)은 아직 다루지 않는다.
- 데이터(대화 목록, 번역 캐시)는 브라우저 localStorage에 저장된다 — 브라우저 데이터를 지우면 함께 사라진다.
- API 키가 클라이언트 코드에서 직접 쓰이는 구조이므로, 이 페이지를 다른 사람과 공유되는 곳에 올리지 않는다 (개인 전용 사용 전제).
