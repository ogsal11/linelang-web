# LineTranslate Web (Phase 2 대안)

Xcode/Mac 없이 쓸 수 있는 순수 클라이언트 웹페이지 버전. 서버·백엔드 없음 — `index.html` 하나로 끝나며, 브라우저에서 번역 API를 직접 호출한다. **번역 엔진을 Gemini(AI 번역)와 MyMemory(빠른 번역) 중에서 고를 수 있다** (⚙️ 설정 → "번역 엔진 바꾸기").

## 사용법

1. 라인 대화방 → **번역하고 싶은 과거 시점까지 미리 위로 스크롤해서 화면에 불러온 뒤** → 설정 → 대화내용 내보내기 → "파일에 저장" (Files 앱 / 원하는 폴더)
   - 내보내기는 화면에 이미 로드된 대화만 포함한다. 스크롤 안 한 과거 대화는 빠진다.
2. `index.html`을 아이폰 Safari(또는 아무 브라우저)로 열기
   - 로컬 파일로 열거나, GitHub Pages 등에 올려서 URL로 접속해도 됨
3. ⚙️ 설정 → "번역 엔진 바꾸기"에서 원하는 엔진을 고른다(아래 비교 참고). Gemini를 선택했다면 API 키도 입력 — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 구글 계정으로 무료 발급 (카드 불필요). MyMemory는 키/가입이 필요 없어 바로 쓸 수 있다.
4. 📥 버튼으로 방금 내보낸 .txt 선택 → 파싱 → 번역 → 채팅방처럼 표시
   - 번역이 끝날 때까지 로딩 화면(진행률 %)이 뜨고, 100% 완료되면 채팅방이 한 번에 보인다(중간에 부분적으로 노출하지 않음).
   - ⚙️ 설정에서 "번역 완료 시 알림받기"를 켜두면, 다른 화면을 보다가도 브라우저 알림으로 완료를 알 수 있다(브라우저 알림 권한 필요, iOS Safari 등 일부 브라우저는 미지원).
   - 채팅방 우측 하단 ⬆ 버튼으로 맨 위(가장 오래된 메시지)로 바로 이동할 수 있다.

## 번역 엔진 비교

| | Gemini (AI 번역) | MyMemory (빠른 번역) |
|---|---|---|
| 속도 | 느림(LLM이 답을 생성하는 방식) | 빠름(전용 번역 API) |
| 설정 | Google API 키 발급 필요 | 키·가입 불필요, 즉시 사용 |
| 대화 맥락 반영 | 됨(직전 메시지 참고) | 안 됨(메시지별 독립 번역) |
| 이름/@멘션 | 번역하지 않도록 지시 가능 | 그대로 번역될 수 있음 |
| 메시지 길이 제한 | 없음 | 500자 초과 시 번역 실패 |
| 언어 감지 | 자동 | 미지원 — 문자 구성으로 추정(한국어/중국어/일본어/베트남어 판별, 그 외는 영어로 가정) |
| 무료 한도 | 하루 약 250회 API 요청(배치 처리로 실제 소모는 훨씬 적음) | 1인 기준 하루 약 5,000자 |

Gemini 사용 시 무료 티어 입력 데이터가 구글의 모델 개선에 활용될 수 있다고 공식적으로 밝히고 있다. 개인 채팅 번역이라 민감도가 낮긴 하지만, 신경 쓰인다면 결제 등록 후 유료 티어(데이터 미활용)로 전환하는 것도 고려할 것.

## Gemini 배치 번역 및 번역 생략(두 엔진 공통)

- Gemini 선택 시, 메시지는 응답 토큰 안전선(대략 배치당 최대 100개, 또는 예상 출력 토큰 6000 중 먼저 도달하는 조건)에 맞춰 자동으로 묶여 한 번의 요청으로 번역된다. 실패 시(형식 오류 등) 해당 배치 전체가 "번역 실패"로 표시되며, 개별 메시지의 ↻ 재시도 버튼으로 단건 재번역할 수 있다.
- MyMemory 선택 시, 메시지는 동시 5개씩 병렬로 개별 호출되며 한 메시지가 실패해도 나머지는 계속 진행된다.
- 이미 한국어인 메시지(한글 음절/자모 비율 60% 이상)는 엔진과 무관하게 API를 호출하지 않고 원문을 그대로 보여준다.
- (Gemini만) 번역 프롬프트에 사람 이름·@멘션·태그된 이름은 원문 그대로 유지하도록 지시한다.

## 알려진 한계

- iOS Safari는 Web Share Target API/File System Access API를 지원하지 않아 "내보내기 즉시 완전 자동 로드"는 불가능하다. 내보내기 → 파일 선택 1회 탭이 최소 동작이다.
- `parseLineExport()`는 실제 라인 PC(Windows) 내보내기 샘플로 검증된 포맷(`오전/오후 HH:MM<TAB>발신자<TAB>메시지`, 여러 줄 메시지는 큰따옴표로 감쌈)을 기준으로 한다. 라인 앱/OS 버전에 따라 세부 표기가 다를 수 있어, 안 맞으면 `index.html`의 `dateLineRe`/`messageStartRe`를 조정해야 한다.
- 파일 인코딩은 UTF-8을 우선 시도하고, 유효하지 않으면 EUC-KR(CP949)로 재시도한다(`readFileSmart`). 그 외 인코딩(UTF-16 등)은 아직 다루지 않는다.
- 데이터(대화 목록, 번역 캐시)는 브라우저 localStorage에 저장된다 — 브라우저 데이터를 지우면 함께 사라진다.
- API 키가 클라이언트 코드에서 직접 쓰이는 구조이므로, 이 페이지를 다른 사람과 공유되는 곳에 올리지 않는다 (개인 전용 사용 전제).
